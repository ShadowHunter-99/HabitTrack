# 🌿 HabitTrack — Minimalist Habit & Streak Tracker

**HabitTrack** es una aplicación móvil moderna, minimalista y de código abierto (*open source*) diseñada para ayudarte a construir y mantener hábitos diarios sin distracciones, anuncios ni muros de pago.

---

## ✨ Características Principales

* 🎯 **Registro de Hábitos Simplificado:** Crea, edita y gestiona tus objetivos diarios fácilmente.
* 🔥 **Seguimiento de Rachas:** Mide tus días consecutivos de cumplimiento (racha actual y racha máxima).
* ✖️ **Estados Flexibles:** Marca hábitos como completados o como complicados/incompletos para tener un registro realista.
* 📊 **Estadísticas Visuales:** Gráficos semanales/mensuales de hábitos completados vs. complicados.
* 🔒 **100% Offline & Privado:** Todos tus datos permanecen guardados en tu dispositivo mediante almacenamiento local.
* 🎨 **Diseño Material 3:** Interfaz amigable, limpia y adaptada a temas modernos.

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* **Gestión de Estado:** `Provider`
* **Persistencia de Datos:** `sqflite` / `hive`
* **Diseño UI:** Material Design 3
